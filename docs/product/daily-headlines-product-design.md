# 每日头条产品功能设计

## 1. 产品定位

每日头条是一份每天早上 8 点更新的精选日报。它的核心价值不是堆更多资讯，而是帮助读者用更少时间看懂当天的重要变化。

核心承诺：

- 每天固定时间更新。
- 每条新闻可以追到原出处。
- 内容经过去重、分组、排序和摘要。
- 支持网页阅读、微信文本分享和历史回看。

## 2. 用户场景

主要用户：

- 早上通勤、喝咖啡时想快速了解天下大事的人。
- 需要把信息转发给朋友、客户、团队的人。
- 关注科技、财经、国际事件，但不想刷多个平台的人。

典型使用路径：

1. 用户早上打开首页。
2. 先看日期、天气和“今日必看 5 条”。
3. 按板块浏览国内、国际、全网热议、科技、财经。
4. 点击感兴趣的新闻查看详情和原出处。
5. 一键复制微信分享版，转发给别人。
6. 需要回看时进入历史归档。

## 3. 信息架构

### 3.1 首页日报

首页是每天的主阅读页。

页面区域：

- 封面区：日期、更新时间、天气参考、主视觉、价值文案。
- 今日必看：从所有新闻里挑 5 条最值得先看的内容。
- 微信分享版：以微信对话气泡形式展示摘要，支持复制。
- 板块导航：国内官方、国际新闻、全网热议、科技圈、财经投资。
- 新闻卡片区：每个板块 10 条。
- 页脚说明：热榜不等于事实重要性，财经内容不构成投资建议。

### 3.2 新闻详情页

点击新闻卡片后进入新闻详情。

详情页内容：

- 新闻标题。
- 一句话摘要。
- 为什么重要。
- 来源列表。
- 原出处链接。
- 发布时间或抓取时间。
- 所属板块。
- 相关后续追踪。

点击来源链接时打开原站点。

### 3.3 历史归档页

历史归档用于回看往期日报。

功能：

- 按日期列出日报。
- 显示每期更新时间。
- 显示当日关键词。
- 支持查看最近 7 天、最近 30 天。
- 支持按日期打开单日页面。

### 3.4 微信分享页/模块

微信分享模块服务于转发。

功能：

- 自动生成当天微信文本版。
- 支持一键复制。
- 保留天气参考、5 条重点、风险提示。
- 后续可扩展成长图版。

### 3.5 后台审核页

后台审核用于发布前人工把关。

功能：

- 查看自动抓取的候选新闻。
- 删除不合适内容。
- 调整排序。
- 编辑标题和摘要。
- 标记“今日必看”。
- 预览微信分享版。
- 一键发布当天日报。

## 4. 每日更新流程

建议更新时间为每天早晨 8 点。

推荐流程：

- 07:30 抓取新闻源、平台热榜、科技资讯、财经资讯。
- 07:40 进行去重、合并同类新闻。
- 07:45 多源比对，标记来源可信度。
- 07:50 生成摘要、重要性标签和今日必看。
- 07:55 生成网页、详情页、微信文本版。
- 08:00 发布。

失败处理：

- 如果抓取失败，保留昨日页面，显示“今日更新延迟”。
- 如果部分来源失败，页面显示“部分来源暂未更新”。
- 如果某条新闻来源不足，标记“单来源待确认”。

## 5. 数据模型

### 5.1 DailyIssue

字段：

- `date`: 日期，例如 `2026-07-08`。
- `publishedAt`: 发布时间，例如 `2026-07-08T08:00:00+08:00`。
- `updatedAt`: 最后更新时间。
- `weather`: 天气参考。
- `sections`: 新闻板块列表。
- `mustRead`: 今日必看新闻 ID 列表。
- `wechatDigest`: 微信分享文本。

### 5.2 NewsItem

字段：

- `id`: 新闻唯一 ID。
- `section`: 所属板块。
- `rank`: 板块内排序。
- `title`: 标题。
- `summary`: 摘要。
- `whyItMatters`: 为什么重要。
- `tags`: 标签，例如 `必看`、`热议`、`影响市场`。
- `sources`: 来源列表。
- `publishedAt`: 原新闻发布时间。
- `verifiedLevel`: 来源确认等级。

### 5.3 Source

字段：

- `name`: 来源名称。
- `url`: 原出处链接。
- `type`: 来源类型，例如 `official`、`media`、`platform`、`finance`。
- `retrievedAt`: 抓取时间。

## 6. 内容规则

### 6.1 排序规则

排序权重：

1. 公共影响范围。
2. 多源确认程度。
3. 是否影响安全、政策、市场。
4. 平台讨论热度。
5. 是否有后续追踪价值。

### 6.2 摘要规则

摘要要做到：

- 一句话讲清发生了什么。
- 不夸大、不制造恐慌。
- 平台热榜必须标注“热度来源”。
- 财经内容必须标注“不构成投资建议”。

### 6.3 来源规则

每条新闻至少保留一个原出处链接。

优先来源：

- 官方发布。
- 主流媒体。
- 国际通讯社。
- 财经专业媒体。
- 平台热榜页面。

同一事件尽量保留两个以上来源。

## 7. 第一阶段 MVP

第一阶段建议做：

1. 数据驱动日报页面。
2. 每条新闻可点击查看详情和原出处。
3. 历史归档页。
4. 每日 8 点更新脚本。
5. 微信分享文本自动生成。
6. 简单后台审核页。

暂不做：

- 用户登录。
- 个性化推荐。
- 复杂评论系统。
- 付费订阅。

## 8. 第二阶段扩展

后续功能：

- 微信长图生成。
- 邮件订阅。
- 企业微信推送。
- 搜索功能。
- 收藏和稍后读。
- 连续事件追踪。
- 城市天气选择。
- 多语言版。

## 9. 页面流程

```text
每日首页
  ├─ 点击新闻卡片 -> 新闻详情页 -> 原出处链接
  ├─ 点击日期归档 -> 历史归档页 -> 某日首页
  ├─ 点击复制微信版 -> 复制当天微信摘要
  └─ 后台入口 -> 审核页 -> 发布当天日报
```
